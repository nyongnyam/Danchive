# Danchive


**프로젝트 개요**
---
프로젝트의 기획 배경과 개발 목적, 핵심 기능을 정리하고, 시스템 아키텍처 및 사용자 사용 흐름(User Flow)을 기반으로 프로젝트 전체 구성을 설명한다. 

Danchive는 전시회 운영·작품 관리·투표·평가를 하나의 앱에서 제공하는 통합 전시 관리 플랫폼으로, 전시 준비부터 운영, 참여(투표/평가), 결과(수상작)까지의 과정을 디지털화하여 운영 효율과 참여 경험을 동시에 개선하는 것을 목표로 한다.

**배경**
---
기존 졸업작품 전시회는 주로 작품 포스터 전시와 현장 체험 중심으로 운영되어 왔다. 이는 작품을 직접 경험할 수 있다는 장점이 있지만, 실제 운영 과정에서는 여러 한계가 반복적으로 발생하였다.
첫째, 방문객은 부스에 직접 방문해 팀원에게 작품 설명을 듣는 방식에 의존하는데, 팀원이 부재한 시간대가 생기면 작품의 목적과 특징을 충분히 이해하기 어렵다. 또한 개인 일정 등 불가피한 사정으로 전시 현장에 참여하지 못하는 사람들은 작품을 접할 방법이 거의 없어, 전시 경험이 장소·시간에 의해 제한된다. 따라서 앱을 통해 작품 설명과 자료를 제공하면, 부스 상황과 관계없이 누구나 작품 정보를 확인할 수 있고 전시 접근성이 크게 향상된다.
둘째, 투표는 종이 용지 부족, 현장 혼잡 등의 문제로 불편함이 있었고, 경우에 따라 팀명만 보고 투표하는 방식이 사용되기도 해 작품 단위의 선호도나 평점 흐름을 전시 중 실시간으로 파악하기 어려웠다. 더불어 방문객 투표와 교수 평가는 별도로 진행된 뒤 엑셀로 수작업 집계되는 경우가 많아, 결과 산출에 많은 시간과 인력이 소요되었다.
셋째, 전시가 끝난 후 졸업작품을 참고하고 싶어도 각 학과가 포스터 수준의 자료만 보유하는 경우가 많아 접근성과 재활용성이 떨어졌다. 학기별로 작품을 정리해 누적 관리하는 아카이브가 부족하여, 후속 학생들이 선배 작품을 학습 자료로 활용하기 어렵다는 문제가 있었다.
결과적으로, 전시 운영 전반을 통합적으로 지원하고 외부에서도 쉽게 접근 가능한 앱 기반 시스템이 필요하다고 판단하였다.

기존 서비스

유사 서비스를 조사한 결과 “아이디어 붐”과 같은 전시 정보 제공형 웹사이트가 존재하였다. 해당 서비스는 전시회와 출품작의 기본 정보 및 발표 자료를 열람하는 기능에 초점이 맞춰져 있어, 전시 운영 중 참여(투표/평가)와 결과 집계까지 통합 지원하는 측면에서는 한계가 있었다.

Danchive는 이를 보완하기 위해 다음과 같은 차별점을 두었다.
방문객/참여자 투표 Form 제공
교수 평가 Form 제공
수상작 실시간 집계 및 조회
팀(팀장/팀원) 생성 및 관리 기능을 통한 체계적 운영 지원

**목표**

Danchive의 목표는 “전시 전 과정(팀 → 작품 → 전시 → 평가)을 통합 관리하고, 참여를 쉽게 만들며, 결과를 자동화하고, 학기별 아카이브를 구축하는 것”으로 요약된다. 

전시 전 과정 통합 관리
팀 구성(팀장/팀원)부터 작품 등록, 전시회 노출, 투표·평가, 수상작 선정까지 하나의 앱 흐름에서 처리하여 운영을 단순화한다.

작품 정보 접근성 향상(QR 기반 참여 포함)
방문객이 부스에 직접 가지 못하거나 팀원이 부재한 상황에서도 앱에서 작품 정보를 확인할 수 있도록 하여 전시 경험의 제약을 줄인다. QR 기반 접근을 통해 현장 참여도 또한 높인다.

투표·평가 자동화 및 실시간 결과 제공
방문객 투표와 교수 평가를 폼 기반으로 제공하고, 결과를 자동 집계하여 전시 중에도 인기/평가 흐름을 즉시 확인할 수 있도록 한다.

학기별 작품 아카이브 구축
학기별 작품을 누적 관리하여 후속 학생들이 참고 자료로 활용할 수 있도록 하고, 학교 차원의 디지털 아카이브 기반을 마련한다.

플로우 차트

Danchive의 사용자 흐름은 “탐색(조회) – 참여(투표/평가) – 관리(팀/작품)”의 구조로 설계하였다.

탐색(조회) 중심 흐름
전시회 페이지 진입 → 학기 기준 전시 선택
작품 검색/필터(학기/카테고리 등) → 작품 리스트 → 작품 상세
작품 상세에서 설명, 팀 정보 등을 확인

관리(팀/작품) 흐름
팀 생성 → 팀원 초대 → 초대 수락
팀장 권한으로 작품 등록/수정
마이페이지에서 팀/내 정보 확인

참여(투표/평가) 흐름
작품 상세에서 “평가/투표” 진입
방문객/참여자 투표 Form 또는 교수 평가 Form으로 분기
제출 즉시 결과 집계에 반영 → 수상작(또는 순위/결과) 조회






**UI/UX 디자인**

글래스 모피즘 UI 스타일 어플리케이션 개발, 반투명한 카드와 컨테이너 디자인과 블러 처리를 이용해 유리 같은 질감의 UI 구현
전체적으로 푸른색과 흰색의 색 배치와 카드/컨테이너를 활용해 시각적 요소 강화 및 일관화
팀 생성 및 관리, 작품 등록, 수상작 반영, 공지사항 등록 등 UX가 실시간으로 반영되도록 구현
네비게이션 바를 이용해 메인페이지, 전시회 목록, 마이 페이지 3가지 페이지를 자유롭게 이동할 수 있도록 UI 구현

**구현 화면**

랜딩 페이지 → 회원가입 페이지 → 로그인 페이지 → 메인 페이지


회원 가입 시 이름, 학번, 소속 학부, 이메일, 비밀번호를 입력해 회원 가입, 이메일의 양식이 틀릴 경우에 오류 발생
로그인 시 회원 가입 할 때 입력한 이메일과 비밀번호를 입력해 로그인, 존재하지 않는 이메일이거나 옳바르지 않은 비밀번호 일 경우에 에러 메시지 출력, 로그인 성공 시 토큰 발행
로그인 페이지에서 remember me 체크박스에 체크 할 경우 로그아웃 전까지 토큰 유지
로그인 성공 시 메인 페이지 이동, 메인 페이지에는 진행 되고 있는 전시회가 배너로 가장 먼저 표시, 배너에는 다양한 요소 등록 가능, 배너 클릭 시 해당 전시회의 작품 리스트 페이지로 이동
메인 페이지에는 등록한 공지사항이 표시가능, 공지사항 클릭할 시 해당 공지사항의 상세 페이지로 이동
팀 생성 → 팀원 초대 → 초대 수락 → 마이페이지



마이 페이지에는 유저의 이름, 팀 이름, 팀원, 역할, 그리고 등록한 작품의 이름이 상단에 노출, 하단에는 팀 생성, 팀원 초대, 작품 등록, 초대 현황, 비밀번호 재설정, 회원 탈퇴, 로그아웃 버튼이 있음.
마이 페이지에서 팀 생성 버튼을 누르고 팀 이름을 입력하면 팀이 생성, 생성한 유저가 자동으로 팀장 부여
초대할 팀원의 가입할 때 입력한 이메일을 입력하고 초대하면 해당 유저에게 초대 메시지 전송, 초대 수락을 할 경우 팀에 팀원으로서 가입
마이 페이지에 팀 이름, 팀원들 이름과 역할 표시











작품 등록 → 전시회 페이지 → 작품 페이지 → 작품 상세



포스터 이미지를 선택 후, 작품의 제목, 간략한 설명, 상세 설명, 그리고 카테고리를 입력
작품 등록을 할 경우에 현재 진행되고 있는 해당 학기의 전시회로 자동으로 저장
작품 리스트 페이지에서 카테고리/작품 이름/팀명으로 해당 작품 조회 가능
조회하고자 하는 작품의 카드를 클릭하면 작품 상세 페이지로 이동
작품 상세 페이지에서 작품에 대해 입력한 내용과 카테고리, 그리고 등록한 팀의 팀원들 이름 조회 가능












방문객/참여자 투표 및 교수 평가 → 수상작 선정


작품 상세 페이지에서 작품 평가하기 버튼을 누르면 작품 평가 페이지로 이동, 버튼을 누른 유저의 역할이 교수일 경우 교수 평가 페이지, 아닐 경우에는 방문객/참여자 평가 페이지로 이동
방문객/참여자는 해당 전시회에서 평가를 한 번만 할 수 있도록해 인기상 투표에 반영, 2번과 3번 문항을 통해 통계 수집
교수 평가에서는 3가지 문항을 1~5까지의 통계로 수집해 평가에 반영, 교수 유저는 모든 작품에 대해 평가 가능
교수가 해당 전시회의 모든 작품에 대해 평가를 완료할 경우 해당 전시회의 평가 종료, 수상작 선정 
수상작은 작품 리스트 페이지의 상단에 순서대로 노출, 각 카드의 우측 상단에 어떤 상을 받았는지 표시










**기대효과**

전시 운영 효율화
작품 등록·관리, 투표·평가 집계를 통합하여 운영 부담과 실수를 감소

관람 경험 개선
부스 부재/혼잡과 무관하게 앱에서 작품 정보를 확인하고 참여 가능

투표·평가 자동 집계
결과 산출에 소요되는 시간과 인력 절감, 전시 중 즉시 결과 제공

학기별 아카이브 구축
작품이 누적되어 후속 학생의 학습 자료로 활용 가능

**결론**

Danchive는 졸업작품 전시 운영을 앱 기반으로 통합하여, 전시 준비부터 운영, 참여(투표·평가), 결과 관리(수상작)까지 하나의 흐름으로 연결한 전시 관리 플랫폼이다. 이를 통해 운영자는 작품 데이터를 체계적으로 관리하고 결과 집계의 부담을 줄일 수 있으며, 참여자는 부스 방문 여부와 관계없이 작품을 이해하고 투표·평가에 참여할 수 있는 경험을 제공받는다. 또한 학기별 작품이 누적되는 구조를 통해 졸업작품이 단발성 전시를 넘어 학과 차원의 디지털 아카이브로 확장될 수 있음을 확인하였다. 

**향후 발전 방향**

포트폴리오 자동 생성 및 외부 플랫폼 연동
